# Dérive Home — Context-aware Experiences → Location → Dynamic Content

A full-stack, context-aware spatial experience for the places we live. Location and everyday context drive what the interface surfaces — a spatial memory map where places, stories, and media are organized around where you are and what that place means, not just where it sits on a map.

Where the Paris work explores cities as cultural landscapes, this work explores a smaller, more personal scale: the rooms, streets, and routines that make up a lived environment. The underlying question is the same, and it is a context-aware UI question as much as a data question: how should an interface change when the user's situation changes?

What this system explores:

- How spatial memory can be represented so that everyday places carry meaning, not just coordinates.
- How a full-stack map experience stays coherent across location, content, and interaction state.
- How multimodal content — place, story, and media — can be presented in a way that adapts to context without overwhelming the user.
